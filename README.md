# MindEase AI 🧠✨
> Your emotional first aid kit! This cost-effective tool uses real-time Sentiment Analysis to turn "feeling low" into "finding help."

## 🚀 Overview
MindEase AI is a web-based mental health assistant built for the Axiora Hackathon Track 1: AI Applications. 

## ✨ Key Features
* **Real-time Sentiment Analysis:** Detects emotional tone in user text.
* **Mood Dashboard:** Visualizes emotional patterns for the user.
* **Resource Integration:** Provides instant wellness suggestions and emergency contacts.
* **Cost-Effective & Scalable:** Built with open-source Python libraries.

## 🛠️ Tech Stack
* **Language:** Python
* **AI/ML:** TextBlob / NLTK (Sentiment Analysis)
* **Frontend:** Streamlit
* **Platform:** Google Colab
